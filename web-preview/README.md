# web-preview — временная веб-сборка Code Labs

Это **собранный бандл**, извлечённый из `CodeLabs-1.6.2.apk` (и побайтово совпадающий
с бандлом внутри `resources/app.asar` Windows-версии). Здесь **нет исходного кода** —
только минифицированный результат сборки Vite.

Зачем: чтобы получить рабочую веб-версию на Vercel, пока исходники недоступны.
Синхронизация работает, потому что приложение ходит в тот же Neon, что десктоп и Android.

## Важно

Эту папку **нельзя редактировать осмысленно** — код минифицирован. Любое изменение
в приложении требует пересборки из исходников, после чего эта папка станет неактуальной.

Как только появятся исходники, правильный путь — подключить их репозиторий к Vercel
напрямую (см. `docs/web/README.md`), а эту папку удалить.

Версия: 1.6.2
